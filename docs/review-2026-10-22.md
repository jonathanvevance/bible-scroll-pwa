## Data safety (fix first)

Fixed in refactor phase 1 (v127). #1 also counts likes and skips the first-backup warning after a restore.

- [x] **1. P1: the first backup after a reinstall can replace the full iCloud backup.** `app.js:1481` `shareBackup`. The "fewer reflections than last time" warning reads `lastBackupCount` from localStorage, which is wiped with the data it protects (reinstall, iOS eviction, new phone). The first backup then silently overwrites the old file of the same name.
  Fix: when this device has no `lastBackupAt` but has data, confirm before sharing and offer "Restore your earlier backup first". Count likes in the shrink check too (store `lastBackupLikes`).
- [x] **3. P2: deleting the reflection being edited, then tapping Done, brings it back.** `app.js:730`. The delete handler does not clear `editing`, so `saveDraft` (`app.js:850`) calls `journal.update` on the deleted record.
  Fix: after `await journal.delete(c)`, `if (editing?.id === c.id) setEditing(null);`.
- [x] **4. P2: tapping Edit on another reflection discards the edit in progress.** `app.js:822` only saves a new draft before switching, not an edit.
  Fix: if `editing` and the text changed, `journal.update(editing, text)` before `setEditing(comment)`.
- [x] **5. P2: a half-written reflection is lost if iOS kills the app in the background.** `app.js:861`. The text is saved only when the sheet closes.
  Fix: on `visibilitychange` to hidden (and `pagehide`) while the sheet is open, call `saveDraft()`.

## Lower-confidence risks

- [ ] `backedUp()` runs when the share sheet resolves, whatever target was chosen, so the reminder can go quiet without a file reaching iCloud. Won't fix: the web can't tell where the file went.
- [x] Safari-tab use (not Home Screen) risks iOS's 7-day storage eviction with no warning; `navigator.storage.persist()` result is not checked. Fixed in refactor phase 9: the backup sheet says to add the app to the Home Screen.
- [x] `journal.js:20` has no `onblocked` / `onversionchange` handling for future database upgrades. Fixed in refactor phase 9: an older tab closes its database and says so.
- [x] `sw.js:54` can store a newer file into an older version's cache on a cache miss. Fixed in refactor phase 8: misses are never stored.
- [x] If `prepareBackup` fails, the backup buttons stay disabled until the data changes. Fixed in refactor phase 9.
- [x] `shareBackup` has no in-flight guard; a double tap raises an `InvalidStateError` alert. Fixed in refactor phase 9.
- [x] If IndexedDB fails to open, `start()` rejects and reading the Bible is blocked too. By design (refactor phase 9): reflections written without the database would be lost; the message now says what failed.
- [x] The History menu is a `<div>`, not a `<dialog>`, so `anySheetOpen()` doesn't see it and auto-advance can run while it is open. Fixed in refactor phase 9: opening it stops auto-advance.
