# Notes for agents

Read `CODING_STANDARDS.md` before changing code; it says how code here is written and what must never happen to the person's data. Run `tests/run.sh` before every commit, and check changes to touch handling, sheets, the feed or saved data against `docs/device-checklist.md` in the simulator. Bump `VERSION` in `sw.js` when any file the app loads changes, then run `python3 pages.py`; never edit the generated files in `ml/`. Open findings are in `docs/review-2026-10-22.md`; the refactor plan is in `docs/plans/`. Work on a branch, never commit straight to `main` (GitHub Pages publishes it), and push only when the owner asks.
